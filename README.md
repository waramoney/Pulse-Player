# Pulse Player v1.3.8 — 개인용 음악·동영상 플레이어

안드로이드 8.0(API 26) 이상. 원본 HTML/Java/Kotlin 없이 Java Android 앱과 HTML UI의 단일 소스 수정본입니다. 기존 음악 재생·플레이리스트·가사·YouTube 즐겨찾기·공식 YouTube 임베디드 재생 기능을 유지합니다.

## 이번 업데이트

### 1. 앱 안에서 음악·영상 이름 변경

라이브러리 → 곡/영상의 **더보기(⋯)** →

- **목록에서 보이는 이름 변경**: 앱/플레이리스트/재생 화면의 제목만 변경하며 실제 기기 파일은 보존합니다. 표시명은 기기 음악 검색 후에도 유지됩니다.
- **휴대폰 원본 파일명 변경**: 실제 음악·영상 파일의 이름을 바꿉니다. 확장자는 변경하지 않으며, Android 파일 제공자가 허용할 때만 실행합니다. Android 11 이상 MediaStore 파일에서는 시스템 변경 승인을 요청합니다. 실패/취소 시 저장 데이터를 삭제하지 않습니다.
- `content://` 문서 파일의 식별자가 바뀌어도 앱 플레이리스트·가사를 새 경로로 연결합니다.

### 2. GitHub·Firebase 없는 오프라인 자동 업데이트 확인

- **설정 → 자동 업데이트 폴더 지정 (한 번만)**에서 폴더를 지정합니다. 휴대폰의 문서/저장소에 `PulsePlayer-v1.3.9.apk`처럼 새 APK 파일을 직접 넣어 주세요. *APK를 내려받는 작업은 사용자가 합니다.*
- 이후 **앱 실행 시 최대 하루 한 번** 해당 폴더에 새 버전이 있는지 확인합니다. 버튼에서 바로 확인하거나 APK를 개별 선택할 수도 있습니다.
- 최신 버전의 앱 패키지명(`com.pulse.player`), 숫자 버전코드, 설치된 앱과 동일한 서명을 검증한 후 업데이트를 제안합니다. APK 복사 후 안드로이드 설치 확인 화면을 엽니다.
- **GitHub, Firebase, 별도 서버, 유료 API, 상시 폴링 사용 없음**. 모든 업데이트 검사는 기기 안에서 끝납니다.
- Android 정책상 무인 설치는 불가능하므로 설치 허가는 이용자가 눌러야 합니다. Google Play 등록도 필요 없습니다.

**꼭 확인:** Android는 기존 앱과 새로운 APK의 서명이 동일한 경우에만 데이터가 유지되는 덮어쓰기를 허용합니다. 예전 GitHub Actions의 매 실행별 디버그 APK는 서명이 달라질 수 있습니다. 서명이 다르면 기존 앱을 백업한 뒤 재설치해야 합니다. 이후 지속적인 덮어쓰기 업데이트에는 처음부터 같은 **개인용 릴리스 서명키**로 빌드한 APK를 사용해야 합니다. 설정법은 [`SIGNING_SETUP.md`](SIGNING_SETUP.md)를 참고해 주세요.

### 3. 기존 재생 기능

- 로컬 음악 백그라운드 재생 (Android 포그라운드 음악 서비스·알림 제어)
- 로컬 MP3/M4A/FLAC/MP4 등 기기에서 지원하는 파일 재생 및 재생속도 선택
- 이름별 플레이리스트, 즐겨찾기, 가사 직접 입력/수정/LRC 타임라인
- YouTube 링크 보관·즐겨찾기·앱 내부 공식 임베디드 재생/PiP 가능한 기기에서 작은 창 재생; Chrome은 명시적 로그인에만 사용
- YouTube 영상 파일 추출/광고 제거/화면을 완전히 끈 상태의 오디오 전용 재생은 제공하지 않습니다. 공식 서비스의 제한을 따릅니다.
- 원본 파일 삭제는 목록에서 숨기기와 별도이며 Android의 확인·승인을 받습니다.

## 소스 검사

```
node --check app/src/main/assets/app.js
node tests/contract.cjs
python tests/browser_integration.py
```

APK 빌드는 Android SDK 35, Gradle 8.9, Java 17을 설치한 컴퓨터에서 가능합니다. Android Studio에서 프로젝트 열기 → Gradle 동기화 → Build APK. 연결된 CI는 빌드용일 뿐, 앱의 업데이트 확인에는 사용되지 않습니다. 실제 휴대폰/YouTube 서버의 모든 재생 제한이 해결되었다고 주장하지 않습니다.
